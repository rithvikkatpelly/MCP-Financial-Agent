# Measured: context and cost

_Generated by `python examples/measure.py` — offline, deterministic. Token counts are the project's ~4-chars/token estimate._

### Result size scales with the range — so the tools require bounds

`get_series_observations` refuses an open-ended request; it needs an explicit `start_date`/`end_date`, and defaults to monthly. A single unbounded daily series is thousands of points.

| Request | Observations | Est. tokens in context |
|---|---|---|
| CPIAUCSL, 2 years, monthly | 24 | ~290 |
| CPIAUCSL, 10 years, monthly | 120 | ~1,346 |
| CPIAUCSL, 25 years, monthly | 300 | ~3,326 |
| DGS10, 10 years, *daily* | 2587 | ~27,189 |

---

### The shrink fallback: thin, don't drop

When a result won't fit the session budget, the observation list is collapsed to every 12th point plus the last one and annotated — the call still returns.

| | Points | Est. tokens |
|---|---|---|
| Full result | 300 | ~3,326 |
| After shrink (budget 900) | 26 | ~344 |

Note added to the payload: _Thinned from 300 to 26 points to fit the token budget._

---

### Over budget → a structured refusal, not a silent dump

A 4-series, 25-year request estimated at ~12,899 tokens, against a 200-token budget, comes back as:

```json
{
  "error": "session_budget_exceeded",
  "estimated_tokens": 12899,
  "budget_remaining": 200,
  "suggestion": "Narrow the date range, reduce the number of series, or start a new session."
}
```

~40 tokens enter the context instead of ~12,899, and the model is told how to retry.

---

### Idempotent cache: repeat calls cost nothing

Five `get_series_observations` calls, two distinct (`CPIAUCSL, UNRATE`): **2 fetches**, 3 served from cache. Live, that's 3 FRED requests (and rate-limit budget) saved.

---

### Most of every turn is prompt-cache-eligible

Tool schemas + all five system prompts come to ~1,090 tokens and are byte-identical across a session. A typical user query is ~26 tokens. Putting the static content first (see `cost_tracker.py`) makes that ~1,090-token prefix a cache hit on every turn after the first — about 90% cheaper on the cached portion.
